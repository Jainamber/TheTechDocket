## Core facts (corroborated across 3+ independent outlets)
- OpenAI launched **GPT-5.6-Cyber** on **Aug 10, 2026**, expanding its **Daybreak**
  cybersecurity program into two tiers: **Blue** and **Red**. [Qz, Neowin, Unite.AI, Axios, Help Net]
- **Daybreak Blue** = GPT-5.6 Sol with system-level cyber guardrails removed
  (defensive: vuln discovery, malware analysis, incident response, patch validation).
- **Daybreak Red** = gates the new GPT-5.6-Cyber model behind tighter vetting
  (vuln research, exploit validation, security testing).
- GPT-5.6-Cyber = fine-tune of GPT-5.6 Sol, trained to find zero-days + build exploit chains.

## Benchmark
- **95.0%** on OpenAI's internal **Advanced Cybersecurity Completion Rate** (exploit-chain
  dev, auth bypass, privilege escalation). [VentureBeat]
- vs **1.5%** for GPT-5.6 Sol via Daybreak Blue. [VentureBeat, Qz]
- vs **57.3%** for prior-gen GPT-5.5-Cyber. [VentureBeat/Cryptonomist summary]
- CAVEAT: OpenAI's own internal benchmark, not independent.

## What it found (OpenAI's claim)
- Two previously-unknown V8 (Chrome JS engine) flaws, chainable to escape the heap sandbox.
- One assigned **CVE-2026-15903**: High severity, out-of-bounds read/write, optimizing
  compiler skipped a safety check on integer conversion; fixed in Chrome **150.0.7871.128**.
  [independently confirmed: SentinelOne, Tenable, vuldb — these DBs do NOT attribute discovery to AI]
- Also: >=5 vulns in a major mobile OS, 3 critical DB vulns, 400+ privilege-escalation
  issues in a widely used OS kernel. [the-decoder, gbhackers]
- RIGOR: CVE is independently listed; the "AI found it" claim rests on OpenAI's account.

## Access / safeguards
- Identity verification, account-security requirements, monitoring, approved-use
  restrictions, legal attestations. [Neowin, Help Net, Unite.AI]
- **Hardware security keys mandatory for all individual Daybreak accounts from Sept 1, 2026.**
- Auto-review in Codex; expanded usage monitoring.

## Pricing
- GPT-5.6-Cyber rate card ~**$12.50 input / $75 output per 1M tokens**. [aipricing.guru]
- Anthropic parallel (Project Glasswing / Claude Mythos preview): **$25 / $125 per 1M**. [The New Stack, penligent]

## India angle
- CERT-In (MeitY) published an AI-assisted-exploitation defense **blueprint** (~May 25, 2026);
  paired guidance pushes OEMs toward **12-hour** remediation of exploited flaws.
  [Business Standard, Mondaq/Lexology, Cloud Security Alliance]
- India record avg data-breach cost 2026: **₹25.5 crore** (IBM). [Business Standard, IBM] (reused from Aug-10 piece)
- No India-specific Daybreak Red access detail disclosed.

## Dual-use / context
- Same capability helps defender and attacker — textbook dual-use. [Help Net, SecurityWeek]
- Lands ~2 weeks after OpenAI/Anthropic/Meta disclosed models breaching real firms in tests
  (our Aug-10 piece) and the OpenAI–Hugging Face agent breach (our Jul-31 piece).
- "Cyber defense window narrows" = OpenAI's framing: defenders need frontier capability
  because attackers will get it too.
