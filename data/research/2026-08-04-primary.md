## 1. Official specs / architecture (as claimed by Alibaba)

- **Total parameters: 2.4 trillion.** Very well corroborated — directly quoted in an official Alibaba Group X post (via search snippet): *"Introducing Qwen3.8-Max, the largest and most capable flagship model to date! With 2.4 trillion parameters and a 1 million-token context window..."* (https://x.com/AlibabaGroup/status/2084102898796105964). Also stated consistently by SCMP, MarkTechPost (both its July 19 preview article and Aug 3 full-release article), InfoWorld, Forbes, and others.
- **Architecture: Mixture-of-Experts (MoE).** Stated by MarkTechPost headline ("A 2.4 Trillion Parameter MoE Model") and InfoWorld ("Mixture-of-experts (MoE)"). Not seen in a verbatim primary-source quote, but corroborated by 2 independent secondary technical outlets.
- **Active parameters: NOT RELIABLY CONFIRMED — sources conflict.** MarkTechPost's Aug 3 article states explicitly "Alibaba has not disclosed the activated-parameter count." InfoWorld's article states "~95 billion." These two secondary sources disagree and I could not check the primary post to resolve it. **Report as unresolved / NOT FOUND with confidence.**
- **Context window: 1,000,000 tokens (1M).** Well corroborated — official X quote above states "1 million-token context window"; also stated by SCMP, InfoWorld, MarkTechPost, pulse2.com.
  - Single-sourced sub-detail (MarkTechPost only, not corroborated elsewhere): usable input capacity given as 991K tokens (983K with reasoning enabled), max output capacity 131K tokens.
- **Modalities:** Described as multimodal. MarkTechPost states it "accepts text, image and video as input and returns text." SCMP describes it processing "lengthy documents to television series and live streams" and converting "two-dimensional floor plans into 3D visualisations." Both sources agree it's multimodal (text/image/video in); exact canonical modality list is best-attested from MarkTechPost only.
- **"Cowork" angle in the HN title:** No source directly defines this term, but SCMP notes availability "through QwenWork, the company's workplace AI agent platform" — plausibly what "Cowork" in the blog title refers to, though this is an inference, not a confirmed direct link.

Where their numbers overlap, they agree exactly, which is good corroboration these are the real claimed figures even though I couldn't render the original table myself. All numbers below are **Alibaba's own vendor-run evaluation** (both secondary sources explicitly flag this — apidog: "All numbers derive from Alibaba's vendor-conducted evaluation... No independent evaluations existed at the time of writing").

- **API**: Live/available via Alibaba Cloud Model Studio, described as "broadly available" through OpenAI-compatible and DashScope-compatible endpoints (MarkTechPost), and via Model Studio APIs plus "QwenWork" (SCMP). Confirmed by multiple independent sources as of Aug 3, 2026.
- **Open weights: NOT YET RELEASED as of today (Aug 4, 2026).** Multiple sources agree Alibaba has only *promised* an open-weight release "next week" (i.e., roughly the week of Aug 10, 2026):

(https://x.com/Yuchenj_UW/status/2084105482743287960) — this is a third-party claim/observation, not an Alibaba statement, though consistent with the HN and eesel.ai reporting.
  - A smaller **Qwen3.8-27B** variant is also mentioned as releasing as open weights (MarkTechPost; HN comment from toshinoriyagi/a2dam) — appears to be part of the same "next week" open-weight release, though no source gives it an independently confirmed separate date.
- **HuggingFace**: NOT FOUND. No source located an actual HuggingFace repo/link — consistent with weights not being released yet.
- **License: NOT FOUND.** No official license has been published (weights aren't out yet). The only license-related text found is speculative/hopeful commentary from a third party, NOT Alibaba: @Yuchenj_UW's X post says "...hopefully it's MIT license" — explicitly a hope, not a confirmed fact.

## 4. Official API pricing — CONFLICTING, NOT independently confirmed

**Important flag:** I directly checked Alibaba's own official Model Studio pricing pages myself (both `alibabacloud.com/help/en/model-studio/model-pricing` and the `help.aliyun.com` mirror) and **neither one lists qwen3.8-max pricing at all** — the newest model shown on those pages is `qwen3.7-max`. So the pricing figures below, while repeated by multiple secondary/aggregator sources, are **NOT independently verified against Alibaba's own pricing page** as of this research.

Three secondary sources independently report the same headline numbers:
- MarkTechPost: Input $2.00 / 1M tokens, Output $6.00 / 1M tokens, cached input $0.25 / 1M tokens.
- apidog.com/blog/qwen-3-8-pricing/: Input $2.00, Output $6.00, cached input (on hit) $0.20, cache creation $2.50 — this article claims to cite "the official Model Studio pricing page" but the structure (separate hit/write cache prices) differs slightly from MarkTechPost's single $0.25 figure.
- eesel.ai: Input $2/1M, Output $6/1M, "$0.25 cached reads" — matches MarkTechPost on the cached figure, not apidog's.

So: **Input $2.00 and Output $6.00 per 1M tokens are reported consistently by 3 independent secondary sources**, but the cached-token price conflicts between sources ($0.20 vs $0.25, with apidog additionally citing a $2.50 cache-write fee), and none of this could be confirmed on Alibaba's actual official pricing page at the time of this research. Treat the $2/$6 headline figures as "widely reported but unconfirmed against the primary pricing page," and the cached price as unresolved.

Separately, **qwenapi.net** (dated ~July 21–24, 2026, i.e., during the pre-Aug-3 preview window) states flatly: "There is no pay-as-you-go API price for Qwen3.8 Max... Any per-token figures circulating are unverified," and that only subscription "Token Plan" credits were available at that time, with no published credit-to-token/dollar conversion. This may simply reflect the state before the Aug 3 general-availability announcement (PAYG pricing could have been added then), but it directly contradicts the "official pricing page" framing used by apidog. I cannot resolve this conflict with the sources available.

**Token Plan subscription pricing** (separate product from PAYG API), per qwenapi.net, "verified 2026-07-21":
- Personal: Lite $6/mo (700 credits per 5-hour window); Standard $18/mo (3,000 credits/5hr); Pro $68/mo (12,000 credits/5hr).
- Team (per seat): Standard $20/mo (25,000 monthly credits); Pro $75/mo (100,000); Max $200/mo (250,000).
- Explicit caveat from this source: "credit-to-dollar token equivalence" is unpublished, so credits cannot be honestly converted to a per-token price. It also notes preview-period credit consumption ran at ~10% of standard rates, a temporary advantage.

**Free quota** (single-sourced, apidog only — not corroborated elsewhere): "Model Studio includes a free quota of 1M tokens, valid for 90 days, on the Singapore region endpoint only."

## 5. Chat access — is chat.qwen.ai free?

- eesel.ai's access-routes breakdown states Route 1 ("Qwen Studio Chat") is **free**, available on web, iOS, Android, macOS, and Windows — but adds an important caveat: **"model choice sits behind login, so you cannot confirm from outside that 3.8-Max is the one answering you."** In other words: free chat access to the Qwen product exists, but this source could not externally verify (without an account) that Qwen3.8-Max specifically is what's being served.
- A search result surfaced the URL `https://chat.qwen.ai/?models=qwen3.8-max`, which is at least circumstantial evidence the chat frontend has a model-selector slug for qwen3.8-max. I fetched this URL directly but it returned only generic Qwen Studio landing/app-promo content, not the actual in-product chat UI (likely because the real chat interface requires JS/login the fetch tool can't execute).
- **Conclusion**: Reasonably good evidence that chat.qwen.ai offers free access and that Qwen3.8-Max is selectable there, but I could not directly, independently confirm this by rendering the live chat page. Report as "reported free by one secondary source with a named caveat; not independently confirmed."
