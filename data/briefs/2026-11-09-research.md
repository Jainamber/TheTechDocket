## 2. The Core Technical Conflict: Claude Code vs. Pi
The migration highlights a growing developer backlash against commercial, "batteries-included" AI coding tools that suffer from feature bloat, high token overhead, and unstable system prompts.

### Claude Code (Anthropic)
* **Status & Pricing**: Launched in May 2025. It is bundled into paid Claude plans: Pro ($20/mo monthly, $17/mo annual), Max ($100/mo), Ultra ($200/mo), or Team Premium ($100/seat/mo annual). It can also be run via pay-as-you-go API keys.
* **Enterprise Spend**: Anthropic's official documentation reports that across enterprise deployments, Claude Code averages **$13 per developer per active day** (approx. **$150 to $250 per developer per month**).
* **Caleb's Technical Frustrations**:
  * **System Prompt Churn**: Claude Code had **244 releases in 2026 alone**. Over 3/4 of these releases modified the system prompt or tool descriptions, constantly altering LLM behavior and sometimes contradicting user-defined repository instructions.
  * **Massive Token Overhead**: The default Bash tool description in Claude Code runs almost **3,000 tokens** (mostly detailing git usage and opening GitHub PRs, which models already know how to do).
  * **IDE Integration Bug**: Connecting the terminal harness to VSCode only supports a single connected session at a time. Opening a second terminal tab to manage a concurrent task breaks the text selection event feed for that second process. This bug has been open since December 2025 and was closed as a duplicate of an unrelated bug.
  * **VSCode GUI Extension Issues**: Half of the built-in slash commands fail to work in the GUI extension, custom status lines are unsupported, and subagent output is layered chronologically into a single messy thread.
  * **The AGENTS.md / CLAUDE.md Marketing Churn**: Anthropic required a proprietary `CLAUDE.md` file in repositories for instructions (which Caleb called "guerrilla marketing"). Just one day after Caleb decided to quit, Anthropic announced support for universal `AGENTS.md` files, which was "too little, too late".

### Pi (Earendil Works)
* **Status & Ownership**: Created in 2025 by Mario Zechner (creator of libGDX). Acquired on April 8, 2026, by **Earendil Inc.** (a public benefit corporation founded by Flask creator Armin Ronacher and Colin Daymond Hanna, backed by Accel, Balderton, and founders of n8n, OpenClaw, Revolut, Sentry, and Slack). Pi 1.0 officially shipped on October 1, 2026.
* **Design Philosophy**: A minimal, model-agnostic terminal coding agent harness (MIT licensed). It operates on the thesis that a coding agent needs exactly four tools—`read`, `write`, `edit`, and `bash`—and a system prompt under 1,000 tokens.
* **Key Features**:
  * **Tiny System Prompt**: Around **200 to 605 tokens** (compared to Claude Code's multi-thousand token prompt).
